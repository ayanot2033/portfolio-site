memoria｜自分だけのオリジナル香水

「memoria」は、自分だけのオリジナル香水を制作できるフレグランスブランドです。

「記憶（memory）」をテーマに、大切な思い出や特別な瞬間を香りとして残すことをコンセプトに制作しました。 香水ボトルやパッケージ、封筒のデザインを通して、記憶を大切に保管するような上品で 特別感のあるブランド表現を目指しました。

01

Package Design

Package Visual

「memoria」のロゴが印象的に伝わるよう、配置や余白のバランスを意識したパッケージデザインを制作しました。

ロゴはブランド名「memoria」の頭文字である「m」を基に、レース調の繊細さと大人らしい華やかさを表現。 模様にも「m」のモチーフを取り入れ、ブランド全体の統一感を演出しました。

02

Package Dieline

Package Layout Design

パッケージを開く前と開いた後で異なる印象を与えるため、 外側は白を基調とした上品なデザインに、内側は黄色を取り入れた華やかな色彩設計にしました。

内外のコントラストによって、開封時に明るく印象に残る変化を演出し、「memoria」の開けた時の特別感を表現しました。

03

Point Card

Elegant Brand Identity

ポイントカードは、「memoria」のロゴをそのまま活かしたフォルムを採用し、 ブランドらしさを印象付けるデザインに仕上げました。 シンプルな構成の中にも上品さとエレガントな雰囲気を取り入れ、 日常的に使用するアイテムとしてブランドの世界観を感じられるデザインを目指しました。

04

Envelope Design

A Surprise Inside

封筒の外側はシンプルな白を基調とし、 内側にはブランドカラーである黄色のパターンを施しました。 開封した瞬間に視覚的な楽しさや驚きを感じられるよう工夫し、 細部までブランドの世界観を体験できるデザインを目指しました。

05

Fragrance Blotter Design

Interactive Brand Experience

「memoria」のロゴである「m」をモチーフに、組み合わせや配色を変えた8種類のムエット紙をデザインしました。 それぞれ異なるパターンを展開することで、香りを試す時間そのものが楽しい体験となるよう工夫しています。 ブランドの世界観を表現しながら、手に取るたびに新しい印象を感じられるデザインを目指しました。

06

Handkerchief Design

Logo Handkerchief

「memoria」のロゴを配置し、ブランドの象徴性を引き立てたハンカチです。 シンプルで上品なレイアウトにすることで、高級感とエレガントな印象を表現しました。 ブランドアイテムとして、世界観を身近に感じられるデザインを目指しています。

Pattern Handkerchief

「memoria」の「m」で構成した模様のハンカチです。 日常使いしやすく、さりげなくブランドの世界観を感じられるデザインに仕上げました。 実用性とデザイン性を両立し、ブランドの認知度向上にもつながるアイテムを目指しています。
