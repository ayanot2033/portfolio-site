ウミガメの泪｜お土産グランプリ

「ウミガメの泪」は、絶滅危惧種であるウミガメの保護活動を支援することを 目的とした、徳島県美波町のお土産ブランドです。

商品のモチーフには小亀を採用し、海をイメージした淡い青色の塩飴としてデザイン しました。 お遍路さんや夏場の塩分補給を必要とする方にも親しまれる商品を目指しています。 売上の10%をウミガメの保護活動へ寄付する仕組みを取り入れることで、お土産を 購入することが地域や環境保全への支援につながるブランドとして企画・制作しました。

Project Overview

A Souvenir Branding Project

絶滅危惧種であるウミガメの保護活動を支援する
徳島県美波町のお土産ブランド。
売上の10%を保護活動へ寄付し、
環境保全への想いを込めて制作しました。

02

Package Design

Package Visual

ウミガメの卵の球体から着想を得た丸みのある形状と、
海辺で使用される浮き輪をイメージした亀甲結びの構造を
取り入れ持ち運びやすいパッケージへ展開しました。

カラーは白と赤を組み合わせることで視認性を高め、
店頭でも印象に残るデザインを目指しました。

Package Detail

外側の白いパッケージとは対照的に、
内部は海をイメージした青色で展開。

深海へ進むような色彩の変化と小亀型の飴によって、
ウミガメが卵から海へ旅立つ物語を表現しました。

03

Promotional Banner

Souvenir Campaign

ブランド名と販売場所である薬王寺を メインビジュアルとして配置したのぼりデザイン。

お遍路さんや観光客が訪れる場所で、ブランドの認知向上と 世界観の伝達を目的に制作しました。

04

Omikuji Card Design

Umigame Mikuji

パッケージの中に入っているおみくじ。 おみくじを通してブランド体験を楽しめるよう デザインしたアイテム。

Pop
